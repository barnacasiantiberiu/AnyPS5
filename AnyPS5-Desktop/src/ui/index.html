Game input

Applied whenever you launch a game from AnyPS5 Desktop. The first controller recognized by SDL is used automatically, including supported Xbox, PlayStation and generic gamepads.

Controller → PlayStation

A / B / X / Y
Cross / Circle / Square / Triangle
LB / RB · LT / RT
L1 / R1 · analog L2 / R2
Start · sticks · D-pad
Options · movement · directional buttons

Default deadzones: 0%; mouse sensitivity: 1×. Increase a deadzone if a stick drifts. Keyboard and mouse keep AnyPS5's built-in bindings: WASD for the left stick, Enter/Space for Cross, Esc for Options, and middle mouse to capture/release mouse movement.

A custom anyps5-input.ini beside a game's executable takes precedence and stays unchanged. Otherwise, the launcher supplies these settings through ANYPS5_INPUT_CONFIG. Controller bindings stay automatic; the four player profiles do not change in-game routing.

Game resolution

Choose the resolution requested the next time you launch a supported game.

Original resolution is used. Resolution overrides are temporarily disabled because changing video output alone can corrupt rendering. Use the game's own graphics settings where available.

Supported Unity games use this setting at startup. Other games keep their original resolution and show a message when launched. Select Original game resolution to restore a supported game's saved configuration on its next launch.

Close a running game before applying a new resolution. This changes the game's startup configuration, not just its window size.
