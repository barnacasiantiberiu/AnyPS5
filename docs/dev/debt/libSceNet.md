### Functional

- [sceNetEpollWait, sceNetGetsockname, address outputs and timeout options](../../../core/libs/prx/libSceNet/Export.cpp) incorporate the corrections and regression cases from upstream PRs [#4610](https://github.com/boykopovar/AnyPS5/pull/4610), [#4611](https://github.com/boykopovar/AnyPS5/pull/4611), [#4612](https://github.com/boykopovar/AnyPS5/pull/4612), [#4613](https://github.com/boykopovar/AnyPS5/pull/4613) and [#4614](https://github.com/boykopovar/AnyPS5/pull/4614). SCE timeout options 0x1105/0x1106 use microseconds; epoll OUT is 2 and returned events identify the registered socket, clear reserved and preserve user data. These conventions follow the public implementations cited in those PRs, not new console measurements. Address lengths report the bytes copied, following FreeBSD 11.4; Windows unbound sockets return a zero address of their guest family. Five independent PC regressions failed against the original library and passed with the corrections, including IPv4/IPv6 truncation guards, connected peers, writable/readable events and an actual UDP receive timeout. Stream timeout limitations below still apply.
- [sceNetSetsockopt](../../../core/libs/prx/libSceNet/Export.cpp) (libSceNet) sets `SO_RCVTIMEO` and `SO_SNDTIMEO` as the host socket's timeouts. On Windows a receive or send on a stream socket that times out fails with `ETIMEDOUT`, where FreeBSD returns `EAGAIN` or the partial count: Winsock leaves the connection in an indeterminate state after a timeout and reports no partial count ([SOL_SOCKET options](https://learn.microsoft.com/en-us/windows/win32/winsock/sol-socket-socket-options)), so FreeBSD's behaviour needs the timeout waited for without the host option. A receive on a datagram socket that times out fails with `EAGAIN`
- [sceNetSendmsg and sceNetRecvmsg](../../../core/libs/prx/libSceNet/Export.cpp) (libSceNet) copy the scatter/gather list through one host buffer and accept only the flags `sceNetSend`/`sceNetRecv` accept. Sending control data throws; a receive never returns control data (`msg_controllen` 0), since no socket option that queues it is supported
- [sceNetResolverAbort and sceNetResolverStartNtoaMultipleRecords](../../../core/libs/prx/libSceNet/Export.cpp) (libSceNet) follow [shadPS4 net_resolver.cpp](https://github.com/shadps4-emu/shadPS4/blob/811bfcd7d17ed8ae975c477d9ff28abc744e1ca8/src/core/libraries/net/net_resolver.cpp) and [net.cpp](https://github.com/shadps4-emu/shadPS4/blob/811bfcd7d17ed8ae975c477d9ff28abc744e1ca8/src/core/libraries/net/net.cpp), adapted from [PR #3728](https://github.com/boykopovar/AnyPS5/pull/3728). Abort flags 1 and 2 preserve one cancellation for the next forward or reverse lookup when none is running. A running host lookup cannot be interrupted: cancellation is reported as EINTR after it returns, without writing the result. Other flag bits throw; multiple-record flags, including asynchronous requests, remain unsupported as for the Ex form. Timeout/retry arguments remain ignored by the synchronous host resolver. Guest layout, error precedence and cancellation behavior remain unverified on console. PC tests use numeric IPv4 loopback, exact 384-byte results, output guards, invalid inputs, independent resolver state and repeated lifecycles. Existing network tests also cover localhost DNS and sockets. Cancellation racing an active host lookup, resolver destruction during a lookup and allocation failures are not deterministically tested.

- [sceNetShowNetstat and sceNetShowIfconfig](../../../core/libs/prx/libSceNet/Export.cpp) print host diagnostics to stdout. Netstat snapshots guest socket identifiers, flags and shared native handle ownership under the registry lock, then queries local and peer endpoints without holding that lock. Ifconfig lists native IPv4/IPv6 unicast addresses, prefix lengths and interface state through GetAdaptersAddresses on Windows or getifaddrs on POSIX. Closing a guest socket concurrently cannot invalidate the retained native handle; connection state can change during the report, so this is not an atomic OS snapshot. The no-argument signatures agree with [shadPS4](https://github.com/shadps4-emu/shadPS4/blob/23c41333822fe8eca4c609b43119180af63ae4ac/src/core/libraries/net/net.cpp); those declarations are not PS5 ABI measurements. The text format is local to this emulator, not a reproduction of console output. An unavailable endpoint prints `-`; enumeration or output failures return a guest network error. Windows functional tests capture real output for empty registries, unbound sockets, a nonblocking listener, connected TCP peers, IPv4/IPv6 UDP and loopback interfaces, and verify data still traverses the connection after diagnostics. Both new tests failed against the original unimplemented exports. POSIX enumeration, concurrent adapter changes and forced output/allocation failures were not tested. 50/50 implemented exports does not remove the other functional limits recorded above.
